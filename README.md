# Telugu Voice Studio (React + Vite + three.js)

1. Install Node.js 18+ (https://nodejs.org)
2. In this folder run:
   npm install
   npm run dev
3. Open http://localhost:5173 and enter the 6-digit PIN set in the backend (`app.pin`).

Backend address: `.env` -> VITE_API_URL=http://localhost:1818/api (restart `npm run dev` after changes).
